# sk3 人脈マップ

sk3 コミュニティの **人 / プロジェクト / テーマ** の関係を可視化する Web 関係図。
「既存の関係」ではなく、**これから生まれうる関係(意図の地図)** を描くことが目的。

- データの源: 1 つの Google スプレッドシート(コミュニティで共同編集)
- 表示: Web 関係図(ブラウザ、CSV を直接読み込んで描画)
- 反映: ページを開いた(リロードした)時点で最新

詳細仕様は [`docs/spec.md`](docs/spec.md)。

---

## クイックスタート(あなたが進める順)

ワンステップずつのガイダンスは [`docs/setup-guide.md`](docs/setup-guide.md) に書いてあります。
全体の流れだけ先に示します。

1. **GAS でスプレッドシート生成** — [`gas/Code.gs`](gas/Code.gs) を新規 GAS プロジェクトに貼り付けて実行すると、列定義・プルダウン・サンプルデータ込みのシートが自動で出来上がる。
2. **シートを CSV 公開** — 「ファイル > 共有 > ウェブに公開」で各シートを CSV として公開。
3. **`web/config.js` を作成** — `web/config.example.js` をコピーして、スプレッドシート ID と各シートの `gid` を入れる。
4. **Web 関係図を開く** — `web/index.html` をブラウザで開く(または GitHub Pages にデプロイ)。

## 本リポジトリの構成

```
README.md
docs/
  spec.md           システム仕様書(v1.0)
  setup-guide.md    あなた向けの手順書(GAS から関係図公開まで)
gas/
  Code.gs           Google Apps Script: シート一式を自動生成
  README.md         GAS の貼り付け方
web/
  index.html        関係図ページ
  app.js            D3 force シミュレーション + CSV 読み込み
  styles.css
  config.example.js シート ID / gid の雛形
```

## 現状のスコープ

- **内部ビューのみ実装**。公開ビュー(匿名化版)は将来対応。
- **案 A(直接読み込み方式)**。Web が開かれるたびに CSV を取得して描画。サーバー不要。
- 人 → プロジェクト、人 → テーマの 2 種類のリンクのみ。人 → 人は引かない。
