# GAS でスプレッドシートを自動生成する

仕様書セクション 3・4 のとおりに、5 シート(使い方/人/プロジェクト/テーマ/関わり)・
プルダウン・ID 自動採番・サンプルデータをまとめて作るスクリプトです。

## 手順

1. Google スプレッドシートを新規作成(空のもの)。
2. メニュー **拡張機能 > Apps Script** を開く。
3. `Code.gs` の **既存コードを全部消して**、本リポジトリの [`Code.gs`](Code.gs) の中身を全文貼り付け。
4. プロジェクト名は適当でよい(例: `sk3-map-setup`)。
5. ツールバーの関数選択で `setup` を選び、▶ 実行。
6. 初回は権限承認ダイアログが出るので承認する。
7. 完了アラートが出たらスプレッドシートに戻る。
   → 5 つのシートと、各列のプルダウンが出来ているはず。
8. スプレッドシート画面をリロードすると、上部に **`sk3` メニュー** が出る。
9. **sk3 > サンプルデータ投入** を押すと、人 8 名・プロジェクト 3 件・テーマ 4 件・関わり 17 件が入る。
10. 確認できたら、Web 関係図側の設定に進む([`../docs/setup-guide.md`](../docs/setup-guide.md) のステップ 3 へ)。

## 便利機能

- **ID 自動採番**: 「人/プロジェクト/テーマ」シートで、ID 列が空のまま別の列に何か書くと、保存時に
  `P001` / `PJ001` / `T001` ... と自動で埋まる。`onEdit` トリガで動作。
- **プルダウン参照**: 「関わり」シートの「人ID」は「人」シートの ID 列を参照したプルダウン。
  「対象ID」は (プロジェクト + テーマ) の和集合なので、Google スプレッドシート仕様上は
  自由入力 + ガイドテキスト表示にしてある(`sk3 > データ点検` で実態を検証)。
- **データ点検**: メニュー `sk3 > データ点検` で、必須列の空欄、ID 重複、存在しない参照などを
  一覧表示。

## やり直しは安全

`setup` は何度実行しても OK。既にあるシートは触らず、無いものだけ作る。
列定義を編集したい場合は、いったんシートのヘッダ行を直接書き換えてから `setup` を再実行。
